PYTHON TOOL DEPLOYED

SDR Zip Sorter

Desktop automation tool for organizing state assessment files.

> Problem

District SDR assessment files required manual extraction and sorting across multiple testing categories, creating repetitive work and inconsistent folder structures.

> Solution

Built a Python/Tkinter desktop tool that allows users to select an SDR ZIP file, choose TestHound or ODS mode, select an output folder, and automatically sort files into standardized folders with an unsorted file log.

Python Tkinter VS Code ZIP Processing Windows Automation

> Impact

  • Reduced manual file organization work.
  • Standardized SDR folder output for assessment workflows.
  • Created a simple GUI for non-technical users.
  • Generated logs for unsorted files and review.
POWER BI ANALYTICS

Campus Snapshot Dashboard

Multi-year accountability and student demographic reporting.

> Problem

Campus leaders needed a fast way to view accountability ratings, enrollment, demographics, and student group indicators without digging through multiple reports.

> Solution

Designed a Power BI dashboard that combines accountability rating history, enrollment counts, grade-level distribution, demographic groups, and student support indicators into one interactive campus view.

Power BI DAX Data Modeling TEA Accountability Operational Reporting

> Impact

  • Created a single-page view for campus performance context.
  • Improved leadership access to accountability and demographic data.
  • Enabled filtering by student groups and campus indicators.
  • Supported data-informed conversations with campus teams.
POWER BI EARLY WARNING

Graduation Early Warning System

> Solution

Power BI DAX Student Analytics Data Modeling Executive Reporting

> Impact
