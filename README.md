# maricia-exe

Personal portfolio website for Maricia Alleman, built as a static HTML/CSS site with a retro terminal-inspired design.

Live site: https://maricia.com

## About

This site serves as my professional and creative portfolio. It includes selected data projects, software projects, games, resume information, and a public-facing job search analytics page built with privacy-safe data.

## Features

- Retro terminal-style interface
- Portfolio project pages
- Resume page
- Games and apps section
- Public analytics dashboard
- Responsive HTML/CSS layout
- Static deployment through Netlify

## Project Areas

- K-12 education data analytics
- Assessment and accountability reporting
- Dashboard and reporting workflows
- Automation tools
- Software and game development

## Privacy Note

This portfolio does not contain student-level data, confidential district records, or private employer information. Any public examples are either synthetic, generalized, or privacy-safe.
